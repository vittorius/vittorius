# Hi there 👋

I'm Viktor Zahorodnii, a software engineer from Ukraine
<sub><img src="https://raw.githubusercontent.com/vittorius/vittorius/refs/heads/main/icons/flag-ua.svg" width="20" height="20" alt="Ukraine" /></sub>.

After 10+ years of pleasant web development using Ruby on Rails
<sub><img src="https://raw.githubusercontent.com/vittorius/vittorius/refs/heads/main/icons/ruby.svg" width="20" height="20" alt="Ruby" /></sub><sub>&nbsp;<img src="https://raw.githubusercontent.com/vittorius/vittorius/refs/heads/main/icons/rails.svg" width="20" height="20" alt="Rails" /></sub>,
I've decided to follow my heart into the land of programming languages, interpreters,
compilers, and systems programming.

My main workhorse is Rust
<sub><img src="https://raw.githubusercontent.com/vittorius/vittorius/refs/heads/main/icons/rust.svg" width="20" height="20" alt="Rust" /></sub>.
I'm also interested in OCaml
<sub><img src="https://raw.githubusercontent.com/vittorius/vittorius/refs/heads/main/icons/ocaml.svg" width="20" height="20" alt="OCaml" /></sub>,
less Haskell
<sub><img src="https://raw.githubusercontent.com/vittorius/vittorius/refs/heads/main/icons/haskell.svg" width="20" height="20" alt="Haskell" /></sub>,
and aspiring systems programming languages, especially with the focus on memory
safety and performance.

## Projects

- <sub><img src="https://raw.githubusercontent.com/vittorius/vittorius/refs/heads/main/icons/rust.svg" width="20" height="20" alt="Rust" /></sub>
  [Zed Settings Sync](https://github.com/vittorius/zed-settings-sync/): a
  settings sync extension for Zed editor that monitors changes in user settings
  files and syncs then into a Github Gist
- <sub><img src="https://raw.githubusercontent.com/vittorius/vittorius/refs/heads/main/icons/rust.svg" width="20" height="20" alt="Rust" /></sub>
  [Lox interpreter](https://github.com/vittorius/lox-interpreter-rs/): a Lox
  interpreter written in Rust while following the
  ["Build your own Interpreter" Challenge](https://app.codecrafters.io/courses/interpreter/overview)
  at CodeCrafters that represents the interpreter part of the
  [Crafting Interpreters](https://craftinginterpreters.com/) book by Robert
  Nystrom.
- <sub><img src="https://raw.githubusercontent.com/vittorius/vittorius/refs/heads/main/icons/rust.svg" width="20" height="20" alt="Rust" /></sub>
  ["Build your own Claude Code" Challenge](https://github.com/vittorius/codecrafters-claude-code-rust):
  a simple Claude Code-like harness for an LLM that exhibits the main features
  of an AI coding assistant: agent loop, using skills, running scripts within
  skills, etc.
